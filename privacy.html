プライバシーポリシー（AI仕事ハック研究所 運営ツール）

制定日：2026年10月27日

1. このツールについて

「AI仕事ハック研究所 運営ツール」（以下「本ツール」）は、YouTubeチャンネル「AI仕事ハック研究所」の運営者が、自分のチャンネルを管理するためだけに使う個人用のツールです。運営者以外の利用者はいません。

2. 取得する情報

本ツールは、運営者本人が許可した範囲で、Google（YouTube Data API・YouTube Analytics API）から次の情報を取得します。

  • 運営者のYouTubeチャンネルの基本情報（チャンネル名、登録者数、動画数など）
  • 運営者が投稿した動画の情報と、再生回数などの分析データ
  • 市場調査のための、YouTube上で公開されている動画の公開情報（タイトル、再生回数など）

3. 利用目的

  • 運営者のチャンネルへの動画のアップロード、公開設定、サムネイル・再生リストの設定
  • 運営者のチャンネルの再生状況の分析
  • 動画の企画のための市場調査

4. 保存と管理

取得した情報と認証情報（アクセストークン）は、運営者のパソコンの中にだけ保存します。外部のサーバーには送信しません。

5. 第三者への提供

取得した情報を、第三者に提供・販売・共有することはありません。

6. Google API サービスのユーザーデータに関するポリシーの順守

本ツールによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

YouTube のデータの利用には、YouTube 利用規約とGoogle プライバシーポリシーも適用されます。

7. 許可の取り消し

本ツールへの許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）からいつでも取り消せます。

8. お問い合わせ

AI仕事ハック研究所（YouTubeチャンネル）までご連絡ください。
